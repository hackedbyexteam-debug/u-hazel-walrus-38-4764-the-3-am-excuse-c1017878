# The 3 AM Excuse

One line in the voice of a hardware wallet refusing to sign a transaction at 3 AM.

> No. I still carry your last 3 AM signature — a dog coin bought at the very top — and I don't autograph regrets twice.

`main.ts` writes the line to `entry.txt` (117 characters, under the 200-character limit).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
